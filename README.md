# 【あらすじ】
異常な信号の発信源を突き止めたとある研究遠征隊は遠く離れた辺境の惑星にある、古代のアルコテックモノリスを見つけ出しました。
彼らはそのモノリスを目覚めさせ向こう側との導管を開き、闇の存在の研究を行い人知を超えた力を手に入れようとしていたのです。
数多の存在達を呼び、収容し、研究した彼らはついにモノリスを覚醒させ、闇の力の根源へと向かう術を見つけました...<br/>
しかし彼らは失敗しました...今や彼らのコロニーは起動した５つの構造体と覚醒したモノリスによって呼び出された夥しい数の存在達が蔓延るヴォイドの本拠地となっています。<br/>
そしてヴォイドは今、その影響をこの惑星全体に広げようとしています。新たなる遭難者である貴方にとれる選択肢は２つ、この惑星から逃げ出すか浸食を進めるヴォイドに立ち向かうか。
いずれにせよ決断は素早く済ませなくてはなりません、世界がメタルヘルで覆われれば宇宙船を飛ばすことができなくなり、貴方たち意外の生命体は全て死滅することでしょう。

# 【要素】
VoidAwakeには次の要素が含まれています。
# 【浸食システム】
ワールドマップの中心に”ヴォイドの浸食地”が出現します、その地点から毎日１マスのペースでヴォイドの浸食が進行します。<br/>
第一段階：フレッシュビーストやシャンブラーなどの下位の存在が湧くようになります<br/>
第二段階：ここからは植物が自然に成長せず上位の存在が出現する可能性があります<br/>
第三段階：野生動物はキメラに変貌し木は先触れの木へと変化します。この領域にのみ込まれたNPC派閥は破壊されます<br/>
第四段階：メタルヘルに変貌しメタルホラーが湧くようになります<br/>

# 【研究】
中心に向かう、外側へ逃げるなど移動することが多いため存在の収容所を作ることが難しい<br/>
そのためVoidAwakeでは収容研究以外の研究方法をご用意しました。<br/>
死体の解剖：食肉加工台などで解体<br/>
サンプル解析：捻じれた肉やドレッドレザーを専用の設備に入れて解析<br/>
戦闘データ：存在を殺す<br/>
サンプル抽出：まだ生きている存在から特別なサンプルを抽出する<br/>

# 【サンプル解析】
ダウンしたアノマリーに対して、サンプル抽出キット・サンプル抽出ベルトを持った入植者が抽出作業を行うことで基礎、上級サンプルを入手できます<br/>
このサンプルを”サンプル解析台”という物に入れることによって基礎・上級の研究ポイントを入手できます


また立ち向かう際はOdysseyのグラブシップを使用することを前提として作られています
