# 幽霊船襲来 仕様書

WorldClock 固定枠として発火する幽霊船イベント。
本文の時間・サイズ・間隔はすべて**仮**。実装時に Def 化する。

関連: [WorldClock.md](WorldClock.md)（時計の時・固定枠の発火）

---

## 1. 一言でいうと

ヴォイドの時計が**時4**に進むと、コロニー外周が海洋になり、**幽霊船が海洋リングを周回**する。船は周回しながら**亡霊を陸地へ放ち大砲で砲撃**する。放った亡霊を殲滅すると船が停泊し、進入（ピットゲート型）が解禁される。イベント終了後は船も海洋も消える。

---

## 2. スコープ

### 実装済み / 今回の対象

- 発火（WorldClock 時4 → Incident）
- P1 海洋化（段階浸食・岩復元・角丸島）
- 亡霊種族（白骨見た目・ロングソード・痛覚耐性）
- 船の出現・周回・亡霊放出・砲撃・殲滅後の進入解禁スタブ

### 後回し

- 本格 `MapPortal` / 船内ポケットマップ
- 艦内守備・戦利品・ボス
- 最終アート

---

## 3. 発火

| 項目 | 内容 |
|------|------|
| 種類 | WorldClock **固定枠** |
| 時 | **時4** → Incident `VoidAwake_GhostShipArrival` |
| 対象 | プレイヤーホーム 1 枚 |
| 重複 | 海洋化進行中なら発火しない |

海洋化は Incident が開始。船は**海洋化完了後**に MapComponent がスポーンする。

---

## 4. フェーズ

```mermaid
flowchart LR
  Fire[時4発火] --> Ocean[P1 海洋化]
  Ocean --> Ship[船出現]
  Ship --> Orbit[周回 + 亡霊放出 + 砲撃]
  Orbit -->|放った亡霊を殲滅| Unlock[停泊 / 進入解禁]
```

| フェーズ | 内容 | 仮時間 / 条件 |
|---------|------|----------------|
| P1 海洋化 | 外周を 1 マスずつ海に | 完了まで |
| 船出現 | 海洋リングの岸沿いに幽霊船をスポーン | 海洋化完了直後 |
| 周回 | 岸沿いを回り続ける。亡霊放出＋砲撃 | 放った亡霊が全滅するまで |
| 進入解禁 | 周回停止。進入可能フラグ（ポータル本実装は後） | 殲滅後 |

### レター

| タイミング | 内容 |
|-----------|------|
| 発火 / P1 | 外周が海に。幽霊船が近づく |
| 進入解禁 | 亡霊が倒れ、船が近づき進入できる（スタブ時はメッセージ） |

---

## 5. 海洋化（P1）

（既存実装どおり）角丸矩形の島の外側を海洋化。スナップショットに地形・天然岩・霧。段階浸食。復元時は岩と霧も戻す。

---

## 6. 幽霊船（コロニーマップ）

- Thing: `VoidAwake_GhostShip`（プレースホルダ。仮テクスチャはバニラ船パーツ流用。移動しやすいよう小さめ）
- 海洋セル上を、岸に沿ったパスで周回
- **周回中は進入不可**
- 放った亡霊を殲滅したら停泊し、`CanEnter` 解禁（MapPortal 本実装は次フェーズ）

---

## 7. 亡霊（新存在）

| 項目 | 内容 |
|------|------|
| def | `VoidAwake_Ghost`（PawnKind） |
| 見た目 | Mutant で白骨死体（dessicated body + Skull） |
| 武装 | `MeleeWeapon_LongSword` |
| 痛覚 | シャンブラー相当（`painFactor` 0） |
| 勢力 | `Faction.OfEntities` |

船付近の陸地へ放出。同時生存上限あり。ウェーブ上限まで出したあと、全滅で周回終了。

---

## 8. 砲撃

周回中、一定間隔で建設可能帯のランダムなコロニー建造物へ爆発（モータル相当）。

---

## 9. 終了と復元（全体イベント終了時・後回し可）

進入実装後: 強制送還 → ポケット破棄 → 船削除 → 海洋復元。
