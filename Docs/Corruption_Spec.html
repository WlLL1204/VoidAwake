1. 概要

コラプションは、バニラ Anomaly のフレッシュビースト4種とドレッドメルドを腐敗変異させたエンティティ群です。 個体としての性能・攻撃・収容設定はバニラのコピーですが、 分裂先が腐敗種同士で閉じている点と、 全個体が常時「腐敗の胞子」を撒く点が異なります。

胞子はバニラの腐敗臭ガス（GasType.RotStink）として撒かれるため、 肺腐敗病はバニラの仕組みでそのまま発症します。 それに加えて、本体の周囲にいた者へ独自の致死 Hediff VoidAwake_SporeParasite（胞子寄生）が進行します。

コラプションが接近→ 足元に腐敗臭ガス→ 肺腐敗病+ 胞子寄生が3時間で 100%→ 即死
胞子寄生は治療できません。唯一の対処は胞子の範囲から離れることと、 ガスマスクを着けることの2つだけです。
襲来イベント（IncidentDef）はまだ実装されていません。 現状は Dev Mode の pawn スポーンからのみ出現させられます。

分裂先はすべて腐敗種に差し替えてあり、バニラのフレッシュビーストが混ざることはありません。

4. 腐敗の胞子

抽象 def が持つ VoidAwake.VoidAwake_CompProperties_CorruptionSpore が実体です。 6 体すべてが同じ設定を共有しており、調整は抽象 def の 1 箇所で全体に効きます。

ThingComp VoidAwake_CompCorruptionSpore
排出間隔intervalTicks = 60（1秒ごと）
排出量amountPerEmission 100 × bodySize。実測 60（フィンガースパイク）– 500（ドレッドメルド）
ガス種別バニラの GasType.RotStink（腐敗臭ガス）。独自ガスは定義していない
排出位置本体の足元セル 1 マス。あとはバニラの GasGrid が拡散させる
停止条件未スポーン、Map が null、または pawn が死亡

肺腐敗病

バニラの腐敗臭ガスをそのまま使うのが設計の要点です。 バニラには RotStink の濃度から LungRotExposure を進め、 そこから LungRot へ繋ぐ連鎖が既にあるため、 肺腐敗病について Mod 側では hediff に一切触れていません。 ガスマスクや防毒装備の効果、通知、健康タブの表示もすべてバニラのまま機能します。

バニラの CompProperties_ReleaseGas は一回きりのバースト放出なので、 移動しながら撒き続ける用途には使えません。そのために独自 ThingComp を用意しています。

5. 胞子寄生

肺腐敗病だけでは「近づくと危険」という圧が足りないため、 逃げる以外に解がない致死タイマーとして追加した独自 Hediff です。

判定範囲

判定方式本体を中心とした半径判定（ガス濃度は参照しない）
実効半径parasiteRadius 3.5 × sqrt(bodySize)
判定間隔60 tick（ガス排出と同じタイミング）
対象スポーン済み・生存・RaceProps.IsFlesh の pawn。メカノイドは対象外
ガス濃度で判定していない理由。 見た目に一致させるなら RotStink の濃度を見るのが自然ですが、 それだと放置した腐乱死体の腐敗臭でも寄生が進行し、 コラプションと無関係に入植者が死にます。バニラの挙動を壊すため採用していません。 代償として、風で流れたガスの端にいても寄生は進行しません。

半径に平方根を使うのは、排出量が bodySize 比例＝面積比例なら、半径はその平方根になるという考え方によります。

進行と減衰

HediffDef VoidAwake_SporeParasite（胞子寄生）

1.0 到達時lethalSeverity 1 によりバニラの仕組みで即死
離脱直後leaveGraceTicks 120 tick は据え置き（一瞬離れただけでは減らない）
猶予経過後1 時間あたり 0.1 減衰。満タンからは 10 時間で消滅

シナリオ追加不可（scenarioCanAdd false）

進行は撒く側の ThingComp、減衰は付いた側の HediffComp と役割を分けています。 HediffComp は「最後に曝露した tick」だけを保持し、NotifyExposed() が来ない間は黙って減り続けます。 この形なら複数のコラプションに同時に囲まれても二重進行にはならず、 どれか1体でも範囲内にいれば減衰が止まります。

6. 耐性と対策

進行量に掛ける倍率は ExposureFactor(pawn) が返します。判定順は以下の通りです。

  1. 着用中の装備、または有効な遺伝子に immuneToToxGasExposure があれば倍率 0（＝完全無効）
  2. それ以外は 1 - ToxicEnvironmentResistance（0–1 にクランプ）
主な装備での致死到達時間
装備毒環境耐性免疫フラグ進行倍率致死まで
なし0—1.003 時間
ウォーベール Apparel_WarVeil0.35—0.65約 4.6 時間
布マスク Apparel_ClothMask0.5—0.506 時間
ガスマスク Apparel_GasMask0.8あり0.00進行しない
コラプション本体1—0.00進行しない
ガスマスクは immuneToToxGasExposure を持つため、毒環境耐性 0.8 の計算を経ずに完全無効になります。 Biotech の毒ガス免疫遺伝子も同様です。

コラプション本体は抽象 def で ToxicEnvironmentResistance 1 を持つため倍率が 0 になり、 自分や仲間の胞子で寄生されることはありません。gain <= 0 の時点で早期 continue するため、 severity 0 の hediff が付いて即消えるような無駄も発生しません。 同じ耐性値によって、バニラ側の肺腐敗病も同時に無効化されています。

実装上の注意。 severity が 1 に達した pawn はその場で死に、map.mapPawns.AllPawnsSpawned から即座に外れます。 列挙中にリストが変化するため、走査のたびに一時リストへスナップショットを取ってから回しています。 痙縮ガス（VoidAwake_CompSpasmGasRelease）は死亡させないので直接列挙していますが、 こちらは同じ書き方ができません。
